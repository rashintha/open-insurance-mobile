# Contributor Guide

This guide is for people who contribute code, documentation, or reviews to Open Insurance Mobile. For setup and submission steps, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Who Can Contribute?

Anyone is welcome to contribute. You do not need prior permission — open an issue or pull request and maintainers will review it.

## Ways to Contribute

| Type | Examples |
| --- | --- |
| Code | Features, bug fixes, refactors, tests |
| Documentation | README updates, inline docs, guides |
| Design | UI/UX improvements, accessibility |
| Review | PR reviews, architecture feedback |
| Community | Answering issues, triaging bugs |

## Contributor Recognition

Contributors are recognized in two ways:

1. **Git history** — Every merged pull request is attributed to its author in the repository history.
2. **Contributors section** — The [README](README.md#contributors) displays profile avatars automatically via [contrib.rocks](https://contrib.rocks). Once your PR is merged, your avatar will appear there on the next README render.

No separate signup is required for recognition.

## Review Process

1. A maintainer reviews your pull request for correctness, style, and scope.
2. You may be asked to make changes — this is normal and collaborative.
3. Once approved, a maintainer merges the PR.
4. Your contribution is included in the project and reflected in the contributor list.

## Expectations

### For Contributors

- Follow the [contribution guide](CONTRIBUTING.md)
- Be responsive to review feedback
- Keep changes focused and well described
- Respect existing architecture and conventions

### For Maintainers

- Review PRs in a timely manner when possible
- Provide constructive, specific feedback
- Credit contributors for their work
- Keep contribution paths clear and welcoming

## Questions?

If you are unsure where to start:

1. Look for issues labeled `good first issue` or `help wanted`
2. Read [CONTRIBUTING.md](CONTRIBUTING.md) for the technical workflow
3. Open an issue describing what you would like to work on

Thank you for helping build Open Insurance Mobile!
