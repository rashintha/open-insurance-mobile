## About

Open Insurance Mobile is the Flutter-based mobile application in the [Open Insurance](https://github.com/rashintha/open-insurance-mobile) ecosystem. It provides a native experience across mobile and desktop platforms using a single Dart codebase.

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (Dart `^3.12`)
- Platform SDKs for your target device (Android Studio, Xcode, etc.)

### Installation

```bash
git clone https://github.com/rashintha/open-insurance-mobile.git
cd open-insurance-mobile
flutter pub get
flutter run
```

### Useful Resources

- [Learn Flutter](https://docs.flutter.dev/get-started/learn-flutter)
- [Write your first Flutter app](https://docs.flutter.dev/get-started/codelab)
- [Flutter documentation](https://docs.flutter.dev/)

## Development

```bash
# Install dependencies
flutter pub get

# Run static analysis
flutter analyze

# Run tests
flutter test

# Run on a connected device or emulator
flutter run
```
